## 已确定的兼容规则

- 普通 OpenAI 调度使用上游返回 `stickyHit` 的选号函数，同时保留本项目的
  账号资格检查、排除后重选、共享报价分层回退和并发等待规则。
  新增的 `previous_response_id` 选号路径也传入本地账号资格条件。
- 拼车继续走订阅计费：不扣钱包和用户平台额度，订阅用量与配置的 Key 限制
  仍然生效。拼车不启用 `SimpleModeKeyRateLimitOnly`。
- 上游简单模式的仅 Key 限流计费分支独立保留，该分支也不产生贡献奖励。
- 保留贡献账号、共同所有者、共享报价、拼车、Chat/Kasm 及本地管理设置。
- 前端平台列表采用上游平台目录，兼容 Kimi、智谱及新增平台。
  用户账号池复用额度组件时继续使用用户接口，推荐信息只在管理员界面展示。

## Kimi OAuth 清理范围

- 移除旧用户 Kimi OAuth 创建支持及其专用 Extra 字段写入。
- 管理员及通用创建接口拒绝新增 Kimi OAuth / setup-token 账号；
  Kimi 继续支持 API Key 创建。
- 移除旧 OAuth 授权文案、来源标识及用量刷新按钮。
- 移除 OpenAI 隐私设置与 token 刷新中的冗余 Kimi 排除条件。
- 历史 Kimi OAuth 账号不再自动补建自用分组。
- 保留 Kimi Coding、按量 API Key 接入、模型目录及历史账号的所有权管理兼容。
  本次没有批量删除或迁移数据库中的旧账号。
